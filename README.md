# Escape the Fort: Team Nagni quiz

A practice quiz for **Team Nagni** before the vidyala's *Escape the Fort*
game for Bandi Chhor Divas. Ustad Ji asked the jathedars to have their teams
watch one Basics of Sikhi video, because it will help in the game. This quiz
checks that the team knows what's in it.

Video: [“Diwali – A Festival of Light Animation”](https://youtu.be/3myspuH4zkc), Basics of Sikhi, 11:30.

**Link for the team:** https://singhharteg-prog.github.io/escape-the-fort-quiz/

The repo is public (Harteg's call, 7 Nov 2026: the other teams won't go
looking for it). GitHub Pages serves only the `docs/` folder, so the link
shows the quiz and nothing else. The answer key isn't on the site.

## The two files

| File | Who it's for |
|---|---|
| `quiz.html` | **The team.** Send them the link above, or this one file (WhatsApp, email, AirDrop). It works on iPhones (in the preview that opens when you tap the file), Android and laptops. They answer, put their name at the bottom, tick **Check my answers**, and the page marks every question, says why, links to that moment in the video, and shows a score out of 27 to screenshot and send back. No internet needed except for the video links. Printing it from a browser gives an A4 paper copy (7 pages). |
| `docs/index.html` | The same quiz, built for the link. |
| `answer-key.html` | **The Jathedar only.** Every answer, why, and where in the video it's said. Use it to mark paper copies. Don't send it to the team. |

27 questions in four parts (Chandu's plans · Inside Gwalior prison · The lions
and the release · put the story in order), plus one bonus that doesn't count.

## Rules the questions keep

- **Only what the video says.** Every question has the second it's said
  (`t` in `data/questions.mjs`). The questions were written from the video's
  English captions, which Basics of Sikhi wrote themselves (not auto-generated).
- **One exception, marked:** the bonus question (where Guru Ji's robe can be
  seen today) comes from the video's YouTube *description*, not its narration.
  The page says so, and it doesn't count towards the score.
- Wrong options are made up on purpose. Only the right answers are claims.
- Titles in full: Guru Hargobind Sahib Ji, Guru Arjan Dev Ji, Bhai Hardas Ji,
  Bhai Jetha Ji, Bhai Pirana Ji. Always **Guru Ji**, never "the Guru".
- Options mustn't give the answer away by length or extra detail (e.g. a job
  title on the right name, or one long gurdwara name among short options).
- One caption is unclear: at 2:59 it reads *“Jungle's final instruction…”*,
  probably a mis-typed “Chandu's”. No question depends on who said that line.

## Changing a question

1. Re-watch the moment, then edit `data/questions.mjs`.
2. `node tools/build.mjs` rebuilds both HTML files. It refuses to build if a
   question is malformed, shuffles the options (the same way every build, with
   right answers spread evenly over A–D), and shuffles the order question's
   events.
3. Never edit `quiz.html`, `docs/index.html` or `answer-key.html` by hand. They're generated.
4. Commit and push: the link updates itself a minute or two later.

The page's look is in `src/quiz.css`; the marking rules come from `marking()` in `tools/build.mjs`.

## Things to know

- **The page has no JavaScript, on purpose.** An iPhone opens a sent HTML
  file in a quick preview that never runs scripts (tested on an iPhone 17
  simulator, 6–7 Nov 2026), and there's no way from there to open it in
  Safari. So the marking is CSS only: the right options carry a `data-c`
  attribute, ticking *Check my answers* reveals the feedback, and CSS
  counters add up the score. The rules are generated by `marking()` in
  `tools/build.mjs`. Don't add a script for anything the team needs.
- **The answers are in the quiz's source**, and in this public repo. Anyone
  who goes looking on a laptop could find them. Fine for practice.
- **Answers aren't saved.** Closing the page loses them, so do it in one go.
- After marking, the answers lock. Tapping the button again hides the marks
  and unlocks them; *Start again* clears everything.
- Hosted on GitHub Pages only (free, from `docs/`). Not on Cloudflare.
